# Add: map, search, and commands (artboards v2 · 03, 04, 04b)

Build spec for the **Add** box, taken from the Paper file *Lazar's Playground*, page **Unfold App**:

| Artboard | Shows |
| --- | --- |
| `v2 · 03 · Add — map` | Add before typing: every project's entrances as a map, the **Look in** column, a hover popover |
| `v2 · 04 · Add — search` | Add while typing `refund`: results of every kind across projects, with the preview pane |
| `v2 · 04b · Add — commands` | Add in command mode (`> pub`) |

All values come from `get_jsx` and `get_computed_styles`. Sample data (`storefront-api`, `refund`, `Order lifecycle`, and so
on) is illustrative; the copy that is chrome (labels, hints, buttons) is verbatim and must be kept.

## 0. Colors and tokens used

The designs use raw hex values. Each one is mapped to the Paper file token and to the existing code token in
`ui/src/theme/tokens.css` (light set). **No token** means neither file has one; the implementer must add a token or
pick the nearest.

| Hex | Paper token | Code token (`tokens.css`) | Used for |
| --- | --- | --- | --- |
| `#FFFFFF` | `--color-ground`, `--color-reader-light-surface` | `--color-surface` / `--color-popover` | Dialog, chips, keycaps, popover |
| `#F7F8FA` | `--color-reader-light-canvas` | `--color-canvas` | Footer band, `esc` keycap, popover footer, preview code block |
| `#202126` | `--color-reader-light-text` (= `--color-syntax-plain`) | `--color-text` | Primary text |
| `#656974` | `--color-reader-light-muted` | `--color-muted` | Secondary text, icons, kind tags |
| `#E0E2E7` | `--color-reader-light-border` | `--color-border` | Dialog border, chip border, keycap border |
| `#E2E8F0` | `--color-rule` | **no code token** (code uses `--color-border` `#e0e2e7`) | Internal hairlines (row dividers, column borders), spinner track |
| `#5862C0` | `--color-reader-light-accent` | `--color-accent` / `--color-accent-text` / `--color-focus-ring` | Active tab text, caret, links, primary button, focused chip border |
| `#EDF0FC` | `--color-reader-light-selection` | `--color-selection` | Active tab, selected row, focused chip fill |

| `#0F172A2E` | `--color-ink` at 18% | **no code token** (code `--color-overlay` is `rgb(20 21 26 / 0.28)`) | Scrim |
| `#0F172A0F`, `#0F172A1A` | `--color-ink` at 6% and 10% | **no code token** (code `--shadow-popover` differs) | Dialog and popover shadow |
| `#E6E8EC` | **no token** | **no token** | Project monogram fill |
| `#3F4451` | **no token** | **no token** | Project monogram letter |
| `#DCE1F5` | **no token** | **no token** | Monogram fill on a selected row |
| `#DDE1F7` | **no token** | **no token** | Matched-text highlight in text-match rows |
| `#D5D9F2` | **no token** | **no token** | Keycap border on a selected (indigo-tinted) row |

Shared values used below:

- **Shadow · floating:** `box-shadow: 0 1px 2px #0F172A0F, 0 8px 24px #0F172A1A`.
- **Fonts:** Inter = `--font-sans` (code `--font-ui`); JetBrains Mono = `--font-mono` (code `--font-code`).
- **Caps label:** Inter 11px / 16px, weight 600, letter-spacing `0.06em` (`--tracking-chip`), uppercase, `#656974`.
- **Project monogram (20):** 20×20, radius 5px (no radius token), fill `#E6E8EC`, letter Inter 11px / 14px weight 600
  `#3F4451`, centered. On a selected row the fill is `#DCE1F5`.
- **Keycap (footer):** height 20px, min-width 20px, padding-inline 5px, radius 4px, fill `#FFFFFF`, border 1px
  `#E0E2E7`, centered glyph Inter 11px / 14px weight 500 `#656974` (the `>` glyph is JetBrains Mono, same size).

## 8. Behavior implied by the designs

- `↵` adds the selection to the current page; `⌘↵` adds it on a new page; `⇥` switches kind; `esc` closes; typing
  `>` switches to commands; `↵` runs a command.
- Map (no query) defaults to the **Entrances** kind tab; search defaults to **All**.
- **Look in** filters the map to one project; its counts are entrance counts.
- A project still compiling shows its partial entrances with the compiling line.
- The context string `Adds to “<page>”` names the page Enter adds to.

## Open questions for the implementer

1. **Text-search options** (match case, whole word, regex) are required by R-13 and artboard 00 but **not drawn**.
   Suggest three 24px toggle icons at the right of the Search row, before `esc`, shown on the Text and All tabs.
2. **Look in** exists only in map mode. Decide whether it persists while typing (the doc says it limits Add to one
   project; artboard 04 drops it and widens results).
3. **Kind tabs differ by mode:** map has no `All` and no counts; search has `All` plus counts. Decide whether the map's
   Functions/Files/Text tabs are reachable before typing, and what they show.
4. **Match highlighting** is drawn only for text matches (tinted `#DDE1F7` + 600) and commands (600, no tint).
   Entrance, function, and file names are drawn without highlights. Pick one rule (suggest the text-match style for
   every kind).
5. **On-page mark** is drawn only on map chips; search rows have none. Suggest the same `● on page` group after the
   name.
6. **Placement:** the box is centered on the **window** and its scrim covers the sidebar and tabs. The Publish dialog
   (artboard 12) is centered on the **canvas** with a canvas-only scrim. Pick one rule per overlay type.
7. **Preview code** is drawn without syntax colors; the peek sheet and cards use the syntax tokens. Suggest the
   syntax tokens.
8. **`Publish changes and keep editing`** is a second publish command with no explanation; the doc has only Publish.
   Confirm or drop it. `Move board back to drafts` (here) differs in wording from the board menu's `Move back to drafts`.
9. Only the **selected** state is drawn; no hover style distinct from selection. Suggest hover = `rgb(32 33 38 /
   0.06)` (`--color-hover`) and selection = `#EDF0FC`.
10. **Unmapped colors** (`#E6E8EC`, `#3F4451`, `#DCE1F5`, `#DDE1F7`, `#D5D9F2`, `#B42318`, scrim and shadow alphas),
    radii 5px, 8px, 12px, the 16px input size, and 24px leading have no tokens. Add chrome tokens for them
    (for example `--color-monogram`, `--color-monogram-ink`, `--color-match`).
11. `DELETE` is `#B42318` here; the doc says "DELETE in red" and the code's red is `--color-danger` `#c42020`. Pick one.
12. The doc's contrast floor names `--color-subtle` `#64748B` for secondary text; the designs use `#656974`
    (`--color-reader-light-muted`, code `--color-muted`). Use `--color-muted`.
